**AI 기반 온라인 사기 의심 거래 탐지 서비스**

---

## 1. 프로젝트 개요

* **목표**: 중고거래 플랫폼에서 발생하는 온라인 사기 피해를 예방하기 위해, AI 기반의 거래 위험도 탐지 서비스를 개발
* **대상 사용자**: 중고거래 플랫폼 사용자(당근마켓, 번개장터, 중고나라 등), 플랫폼 운영자, 보안 기업 등

---

## 2. 배경 및 문제 정의

* **중고거래 사기 피해 급증**

  * \[서울신문, 2023.08] "중고거래 피해 3년간 9만 건 넘어… 피해액 250억 원"
  * '같은 물건 반복 게시', '시세보다 지나치게 낮은 가격', '선입금 유도' 등이 주요 수법
* 사용자는 **판매자 신뢰 여부를 주관적으로 판단** → **AI 기반 자동 위험도 분석의 필요성 대두**

---

## 3. 핵심 기능 및 구현 방식

1. **채팅 NLP 분석**

   * 사기 유도 문장(선입금 요청, 비정상적 거래 조건 등) 감지
   * KoBERT 또는 AI Hub의 사기/비사기 채팅 데이터를 기반으로 fine-tuning
   * 채팅 입력 시 REST API 요청 → 예측 결과(사기 확률) 반환

2. **이미지 도용/중복 감지**

   * CLIP 모델을 활용하여 업로드 이미지와 기존 사기 DB 이미지 간 유사도 측정
   * 이미지 검색 API(Google Reverse Image 등) 또는 자체 MongoDB에 저장된 사기 이미지와 비교
   * React에서 이미지 업로드 시 → Spring Boot로 전송 → 유사도 분석

3. **위치/가격 이상 탐지**

   * 평균 시세 데이터(MySQL 기반 지역별 시세 테이블 구축)와 비교
   * 거래 위치 기반 Redis 캐싱 처리로 응답 시간 최소화
   * 가격/위치 이상 탐지 로직은 비동기 Task로 분리 처리

4. **판매자 평판 시각화**

   * 판매자의 거래 이력, 신고 이력, 평점 정보를 종합 분석
   * 데이터는 MongoDB + Redis에 저장 → React 대시보드에서 시각화 차트로 표시 (Chart.js)

5. **위험도 스코어 통합 제공**

   * 위 모든 요소를 가중치 모델로 종합하여 0\~100점 위험 스코어 산출
   * 위험도에 따라 색상 경고(초록/노랑/빨강) 및 경고 메시지 제공

---

## 4. 기대효과

* 거래 전 위험 경고를 통해 **사기 피해 감소**
* 사용자 **심리적 안심감 제공**
* 중고거래 플랫폼의 **신뢰도 향상**, API 제휴 가능성

---

## 5. 기술 스택

| 영역     | 기술                                                                                     |
| ------ | -------------------------------------------------------------------------------------- |
| 백엔드    | Spring Boot, Spring Security, JPA, REST API, MSA 구조 (Gateway / Service 분리)             |
| 데이터베이스 | MySQL 또는 PostgreSQL (구조화 정보), MongoDB (비정형 이미지/로그), Redis (세션/캐싱)                      |
| 프론트엔드  | React.js, TailwindCSS, Chart.js                                                        |
| 인공지능   | KoBERT (사기 채팅 분류), CLIP (이미지 유사도 분석), AI Hub 학습 데이터셋 활용                                |
| 배포/운영  | Microsoft Azure (App Service, PostgreSQL Server, Blob Storage), Docker, CI/CD Pipeline |
| 기타     | 플랫폼 API 연동 (예: 더치트, 당근마켓), OAuth2 로그인                                                  |

---

## 6. 사업성과 확장성

* **중고거래 플랫폼 API 연계**로 실시간 위험도 제공 가능
* **B2C 앱/브라우저 확장 프로그램** 출시 가능
* **사기 보험사** 또는 **전자지갑 앱**과 제휴 가능
