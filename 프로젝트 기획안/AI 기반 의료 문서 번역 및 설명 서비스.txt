1. 프로젝트 개요
프로젝트명: 메디-톡 (임시)

한 줄 소개: AI 기반 의료 문서 번역 및 설명 서비스

프로젝트 비전: 환자와 의료진 간의 정보 격차를 해소하여 환자가 자신의 건강 정보를 주도적으로 이해하고 관리하는 세상

핵심 목표:

정보 접근성: 의료 문서의 이해도를 95% 이상으로 향상

환자 주권: 환자가 자신의 질병 및 치료 과정에 대한 이해를 바탕으로 능동적으로 의료 결정에 참여하도록 지원

불안감 해소: 어려운 의학 정보로 인한 막연한 불안감을 해소하고 심리적 안정 제공

2. 문제 정의 및 타겟 고객
문제점:

전문 용어의 장벽: 진단서, 검사 결과지의 의학 용어는 환자 및 보호자가 이해하기 불가능에 가까움.

짧은 진료 시간: 의사에게 충분한 설명을 들을 시간이 부족하며, 한번 들은 설명을 기억하기도 어려움.

정보 탐색의 오류: 인터넷 검색에 의존할 경우, 부정확하거나 과장된 정보로 인해 오히려 불안감이 증폭될 수 있음.

타겟 고객 (Persona):

초보 부모 이지은 (32세): 아이가 아파서 병원에 다녀왔는데, 처방전에 적힌 약 성분과 진단명이 생소하고 어렵다. 이 약을 먹여도 괜찮은지, 아이의 상태가 얼마나 심각한지 몰라 밤새 걱정한다.

만성질환자 최철수 (65세): 정기적으로 병원에서 검사를 받지만, 매번 검사 결과지의 수치들이 무엇을 의미하는지 정확히 알 수 없다. 의사에게 다시 묻기 미안하고, 자식들에게 물어보기도 부담스럽다.

3. 솔루션 및 핵심 기능 (User Stories)
핵심 기능 1: AI 의료 문서 분석 및 번역

User Story: "보호자 이지은으로서, 나는 아이의 처방전 사진을 찍어 올리면 어떤 병이고 각 약이 어떤 효과가 있는지 쉬운 설명으로 보고 싶다. 그래야 안심하고 아이를 돌볼 수 있다."

세부 기능:

카메라/앨범을 통한 의료 문서(진단서, 처방전, 검사 결과지) 이미지 업로드

**Azure Computer Vision(OCR)**을 통한 텍스트 추출

추출된 의학 용어를 일상 용어로 번역 및 설명 (예: 'AST/ALT 수치 상승' -> '간세포가 손상되었을 때 높아지는 수치로, 간 기능 저하가 의심됩니다.')

핵심 기능 2: 용어별 상세 설명 및 관련 정보 제공
AI 활용(AI-Hub) : https://www.aihub.or.kr/aihubdata/data/view.do?pageIndex=1&currMenu=115&topMenu=100&srchOptnCnd=OPTNCND001&searchKeyword=&srchDetailCnd=DETAILCND001&srchOrder=ORDER001&srchPagePer=20&srchDataRealmCode=REALM006&aihubDataSe=data&dataSetSn=71874

User Story: "만성질환자 최철수로서, 나는 번역된 결과에서 특정 질병이나 약품 이름을 클릭하면 더 자세한 정의와 주의사항을 확인하고 싶다. 그래야 내 병을 더 잘 관리할 수 있다."

세부 기능:

번역된 텍스트 내 핵심 키워드(질병명, 약품 성분, 검사 항목) 하이라이팅

키워드 클릭 시 상세 설명 팝업 또는 페이지 이동 (정의, 원인, 관련 증상, 복용 시 주의사항 등)

핵심 기능 3: 분석 이력 관리 및 추이 확인

User Story: "모든 사용자로서, 나는 과거에 분석했던 나의 의료 기록들을 시간 순서대로 모아보고 싶다. 그래야 내 건강 상태의 변화 추이를 한눈에 파악할 수 있다."

세부 기능:

날짜별/병원별 분석 기록 아카이빙

(향후) 특정 검사 수치(예: 혈당, 콜레스테롤)의 변화를 그래프로 시각화

4. 시스템 아키텍처 및 데이터 흐름
시스템 구조:

Frontend (React): 사용자 인터페이스

Cloud (Microsoft Azure): 전체 인프라 호스팅 및 AI 서비스

API Gateway: 보안 및 라우팅 담당

User-Service (SpringBoot): 사용자 관리 (강화된 보안)

Medical-Service (SpringBoot): 문서 분석 처리

Azure Cognitive Services: OCR 기능 제공

Azure Machine Learning: 의학용어 번역 LLM 서빙

Databases:

MySQL/PostgreSQL: 사용자 정보, 문서 메타데이터 (암호화)

MongoDB: OCR 추출 결과, AI 번역 결과 (JSON)

Redis: 세션, 캐시

Security:

Azure Key Vault: 모든 비밀 키 중앙 관리

핵심 데이터 흐름 (의료 문서 분석 요청 시):

[Frontend] 사용자가 React 앱에서 처방전 사진을 업로드하고 '분석 요청' API 호출 (HTTPS 필수).

[Azure API Gateway] TLS/SSL 연결 확인, JWT 토큰 검증 후 Medical-Service로 라우팅.

[Medical-Service] 업로드된 이미지를 임시 저장 후, Azure Key Vault에서 API 키를 가져와 Azure Computer Vision API로 이미지 전송.

[Azure Computer Vision] 이미지에서 텍스트를 추출하여 좌표값과 함께 JSON 형태로 반환.

[Medical-Service] 추출된 텍스트를 Azure ML에 배포된 의학용어 번역 LLM API로 전송.

[Azure ML] LLM이 텍스트를 분석하여 쉬운 설명으로 변환한 결과를 JSON 형태로 반환.

[Medical-Service] 원본 OCR 결과와 최종 번역 결과를 MongoDB에 저장하고, 파일 경로 및 요약 정보는 암호화하여 MySQL에 저장.

[Frontend] 분석 완료된 결과를 받아 사용자에게 원문과 번역문을 나란히 보여주는 화면 렌더링.

6. 사업성 및 기대효과
수익 모델 (Business Model):

B2C Subscription: 월 3회 분석 무료, 이후 무제한 분석 및 분석 이력 추이 확인 기능 등을 포함한 유료 구독 모델.

B2B Solution: 병원, 약국, 보험사 등과 제휴. 병원 EMR(전자의무기록) 시스템에 연동하여 '환자용 쉬운 진단서' 발급 서비스로 제공하거나, 보험사의 보험금 청구 서류 분석 과정에 활용.

기대효과:

사회적: 국민의 의료 정보 문해력(Health Literacy) 향상, 의사-환자 간 신뢰 관계 증진, 과잉진료 및 약물 오남용 방지에 기여.

산업적: 디지털 헬스케어 시장의 새로운 서비스 모델 제시, 마이데이터와 결합하여 개인 맞춤형 건강 관리 서비스로 확장 가능.
