**지자체 민원 데이터 기반 지역 문제 예측 시스템**

## 1. 프로젝트 개요

* **목표**: 민원 데이터를 AI로 분석하여 지역 문제를 시각화하고 예측함으로써 지자체가 선제적으로 대응할 수 있도록 지원
* **대상 사용자**: 지자체 정책 담당자, 공무원, 지역 사회단체, 시민

## 2. 배경 및 문제 정의

* [국민권익위, 2024.04] "최근 3년간 전국 민원 1.1억 건 발생"
* 민원이 반복되고 있음에도 **시각화/예측 기반 정책 수립 미비**
* 수많은 민원이 단순 집계에 그쳐 **실효성 있는 대응이 어려움**

## 3. 핵심 기능 및 구현 방식

1. **민원 NLP 분류 및 군집화**

   * AI Hub 또는 공공데이터포털 민원 데이터를 활용한 텍스트 분류 모델 학습 (FastText, KoBERT)
   * 주요 유형(예: 쓰레기, 불법주차, 소음 등)으로 자동 분류 + DB 저장
   * 동일 유형 군집화(KMeans) 및 유사도 기반 태깅 처리

2. **지도 기반 시각화**

   * 민원 발생 위치를 지도 기반으로 시각화 (Leaflet.js + PostGIS)
   * 날짜, 시간대, 유형별 필터링 가능 (React에서 인터페이스 구현)
   * 핫스팟은 heat map 기반으로 표현하며, 행정구역별 민원 수를 색상별로 표현

3. **문제 예측 시스템**

   * Prophet 또는 LSTM을 활용한 시계열 예측 모델 적용
   * 유형별/지역별로 다음 분기 또는 월별 민원량 예측
   * 예측 결과를 차트와 지도에 함께 시각화하여 대응 시점 확보

4. **행정구역별 비교 대시보드**

   * 민원 수, 처리율, 재민원 발생률 등을 비교 (Chart.js 기반 시각화)
   * 우선 대응 지역 자동 추천 알고리즘 포함
   * 정책 수립/보고서용 PDF 자동 생성 기능 가능 (Spring PDF 생성 라이브러리 활용)

## 4. 기대효과

* **지자체의 민원 처리 효율성 향상**
* **선제적 행정 대응 및 정책 수립 가능**
* **투명한 행정 정보 공개를 통한 시민 신뢰 확보**

## 5. 기술 스택

| 영역     | 기술                                                                     |
| ------ | ---------------------------------------------------------------------- |
| 백엔드    | Spring Boot, Spring Security, REST API, JPA 기반 MSA 구조                  |
| 데이터베이스 | PostgreSQL + PostGIS (좌표 기반 시각화), Redis (민원 캐시), MongoDB (비정형 민원 첨부자료) |
| 프론트엔드  | React.js, Chart.js, Leaflet.js 또는 Mapbox                               |
| 인공지능   | FastText, KoBERT (분류), Prophet / LSTM (예측), AI Hub 민원 텍스트 데이터 활용       |
| 배포/운영  | Microsoft Azure 기반 서비스, Docker Compose 및 Kubernetes 연동 가능성 확보          |

## 6. 사업성과 확장성

* **스마트시티/스마트 행정** 프로젝트와 연계 가능
* **정책 기관·대학 연구소·ESG 분석 기관** 협업 가능
* **민원 처리 SaaS 플랫폼화** 가능
